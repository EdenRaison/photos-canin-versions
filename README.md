# Photos Canin — versions

Ce dépôt ne contient que les fichiers publiés de l'appli **Photos Canin** (aucune donnée, aucune photo) :
`Code.gs`, `Index.html`, `appsscript.json` et `version.json`.

L'appli installée les lit quand on clique sur « Mettre à jour l'appli ». Le code source est dans un dépôt privé.
